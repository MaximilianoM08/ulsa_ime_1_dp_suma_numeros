# Receta: Suma de 5 números

1. Mostrar mensaje de bienvenida
2. suma ← 0.0
3. contador ← 0
4. MIENTRAS contador <= 5 HACER
       Pedir al usuario el número
       Leer número
    SI número ES númerico
       suma ← suma + número
       contador ← contador + 1
    SI NO 
       "Error: No es un valor númerico"
    FIN SI
   FIN MIENTRAS
5. Mostrar suma
